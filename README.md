# Salle Rétro — appli pour Android TV

Lanceur de jeux rétro pour la télé : choisis un jeu à la manette ou à la télécommande, joue à deux sur la même télé
ou en ligne dans un salon.

## Installer sur une télé Android / Google TV
1. Installe l'appli **Downloader** depuis le Play Store.
2. Dans Downloader, tape : `salle-retro.vercel.app/apk`
3. Autorise l'installation quand la télé le demande, puis installe.

Téléchargement direct : [salle-retro.apk](https://github.com/AmineHAMMANI/salle-retro-app/releases/latest/download/salle-retro.apk)
